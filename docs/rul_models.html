rul_models

Remaining useful life (RUL) models for bearing 1 of IMS test 2, and the baseline they are all compared against.

Engineering question: how many hours does this bearing have left?

Baseline (no sensor data) The catalogue rating life, as a maintenance planner would use it: $L_{10} = (C/P)^p \times 10^6$ revolutions, with $p = 10/3$ for roller bearings (3 for ball bearings), converted to hours at the shaft speed. For the Rexnord ZA-2115, $C = 28\,890$ lb. $L_{10}$ is a population statistic (90 % of bearings survive it), so a Weibull distribution converts it to other reliabilities, e.g. the median life $L_{50}$. sklearn.dummy.DummyRegressor (predict the mean training RUL, week 5.5) is a second, data-only baseline.

Candidate models (use the vibration data) * Trend extrapolation (week 3.1, least squares as in week 5.1): fit a straight line to the last window hours of the RMS trend and extrapolate it to a failure threshold. * Linear regression, decision tree and SVR (weeks 5.1 to 5.3) mapping smoothed RMS and kurtosis to RUL.

Tuning knobs (week 3.2, overfitting and noise) No noise is added to the data. Instead the real measurement noise is filtered by trailing_mean with an adjustable window (1 = raw), and flexibility is set by the extrapolation window, tree max_depth or SVR C. Too little filtering or too much flexibility follows the noise (low training error, high test error); too much makes the model sluggish. The smoother only looks backwards, because in service the future snapshots do not exist yet: a centred smoother would leak future information into the features (week 5.6, target leakage).

Evaluation (week 5.5) MAE and RMSE in hours, plus the percentage of late predictions (predicted RUL longer than the true RUL), which are the dangerous ones because maintenance would be scheduled after the failure. Settings are chosen on validation snapshots and the test snapshots are scored once (tune_and_test, tune_fixed); the splits themselves are in splits.

 56def catalogue_life_hours(C=ZA2115_C_LB, P=6000.0, rpm=2000.0, p=10 / 3):
 57    """Basic rating life L10 in hours.
 58
 59    Parameters
 60    ----------
 61    C : float, optional
 62        Dynamic load rating (same units as `P`).
 63    P : float, optional
 64        Equivalent dynamic load on the bearing. IMS tests apply 6000 lb.
 65    rpm : float, optional
 66        Shaft speed in rev/min.
 67    p : float, optional
 68        Life exponent: 10/3 for roller bearings, 3 for ball bearings.
 69
 70    Returns
 71    -------
 72    float
 73        Hours that 90 % of identical bearings are expected to exceed.
 74    """
 75    return (C / P) ** p * 1e6 / (60 * rpm)

 78def life_at_reliability(l10, reliability=0.5, beta=1.5):
 79    """Convert L10 to the life reached with another survival probability.
 80
 81    Assumes a two-parameter Weibull life distribution,
 82    $L_R = L_{10} (\\ln(1/R) / \\ln(1/0.9))^{1/\\beta}$.
 83
 84    Parameters
 85    ----------
 86    l10 : float
 87        Rating life (hours).
 88    reliability : float, optional
 89        Survival probability, 0.5 gives the median life L50.
 90    beta : float, optional
 91        Weibull slope, typically 1.1 to 1.5 for rolling bearings.
 92
 93    Returns
 94    -------
 95    float
 96        Life in hours.
 97    """
 98    return l10 * (np.log(1 / reliability) / np.log(1 / 0.9)) ** (1 / beta)

101def failure_probability(t, l10, beta=1.5):
102    """Weibull probability that a bearing has failed by time `t`.
103
104    Parameters
105    ----------
106    t : float or array_like
107        Running time (hours).
108    l10, beta : float
109        As in `life_at_reliability`.
110
111    Returns
112    -------
113    float or numpy.ndarray
114        Probability between 0 and 1 (0.1 at ``t = l10``).
115    """
116    eta = l10 / np.log(1 / 0.9) ** (1 / beta)
117    return 1 - np.exp(-(np.asarray(t, dtype=float) / eta) ** beta)

138def trailing_mean(y, window=6):
139    """Mean of the current and previous ``window - 1`` values.
140
141    Unlike `trends.moving_average` it uses no future snapshots, so it can be
142    applied in service. ``window = 1`` returns the raw data.
143
144    Parameters
145    ----------
146    y : array_like
147        Indicator values in time order.
148    window : int, optional
149        Number of snapshots averaged (fewer at the start).
150
151    Returns
152    -------
153    numpy.ndarray
154        Filtered values, same length as `y`.
155    """
156    y = np.asarray(y, dtype=float)
157    total = np.concatenate([[0.0], np.cumsum(y)])
158    i = np.arange(1, y.size + 1)
159    lo = np.maximum(i - window, 0)
160    return (total[i] - total[lo]) / (i - lo)

163def extrapolate_rul(t, y, threshold, window=10.0, log=False, max_rul=np.inf):
164    """Predict RUL by extrapolating the recent trend to a failure threshold.
165
166    At each snapshot a least-squares line is fitted to the values in the
167    last `window` hours (only past data). Times are measured from the
168    current snapshot, which keeps the fit well conditioned (week 2.2).
169
170    Parameters
171    ----------
172    t : array_like
173        Hours, increasing.
174    y : array_like
175        Health indicator, usually RMS (g).
176    threshold : float
177        Indicator value treated as failure.
178    window : float, optional
179        Hours of history fitted. Short follows noise, long reacts slowly.
180    log : bool, optional
181        Fit ``log(y)`` instead, i.e. exponential growth.
182    max_rul : float, optional
183        Prediction used when the trend is flat or falling (no crossing).
184
185    Returns
186    -------
187    numpy.ndarray
188        Predicted RUL in hours, between 0 and `max_rul`.
189    """
190    t, y = np.asarray(t, dtype=float), np.asarray(y, dtype=float)
191    if log:
192        y, threshold = np.log(y), np.log(threshold)
193    rul = np.full(t.size, float(max_rul))
194    for i in range(t.size):
195        past = (t <= t[i]) & (t > t[i] - window)
196        if past.sum() < 3:
197            continue
198        slope, now = np.polyfit(t[past] - t[i], y[past], 1)
199        if slope > 0:
200            rul[i] = np.clip((threshold - now) / slope, 0, max_rul)
201        elif now >= threshold:
202            rul[i] = 0.0
203    return rul

206def extrapolate_rul_fast(t, y, threshold, window=10.0, log=False, max_rul=np.inf):
207    """Same result as `extrapolate_rul`, in O(n) instead of O(n^2) time.
208
209    `extrapolate_rul` runs a Python loop that builds a boolean mask over
210    all n snapshots and calls `numpy.polyfit` at every snapshot, so its cost
211    grows as n^2 (in practice the ~50 us overhead of each `polyfit` call
212    dominates at IMS sizes). Here the least-squares sums come from running
213    (cumulative) sums, vectorised over all snapshots, so each window costs
214    a few subtractions:
215    $b = S_{ty} / S_{tt}$ with $S_{tt} = \\sum t^2 - (\\sum t)^2/m$ and
216    $S_{ty} = \\sum ty - \\sum t \\sum y / m$ over the m points in the window.
217
218    Subtracting large running sums loses digits (catastrophic cancellation,
219    week 2.2), so times are first centred on their mean, which keeps the
220    sums small. `test_rul_models` checks the two versions agree to 1e-6 h.
221
222    Parameters and return value are as in `extrapolate_rul`; `t` must be
223    strictly increasing.
224    """
225    t, y = np.asarray(t, dtype=float), np.asarray(y, dtype=float)
226    if log:
227        y, threshold = np.log(y), np.log(threshold)
228    u = t - t.mean()                        # centred times, smaller sums
229    zero = [0.0]
230    S1, Su, Sy, Suu, Suy = (np.concatenate([zero, np.cumsum(v)])
231                            for v in (np.ones_like(u), u, y, u * u, u * y))
232    hi = np.arange(1, t.size + 1)           # window is snapshots lo .. hi-1
233    lo = np.searchsorted(t, t - window, side="right")
234    m, su, sy = S1[hi] - S1[lo], Su[hi] - Su[lo], Sy[hi] - Sy[lo]
235    suu, suy = Suu[hi] - Suu[lo], Suy[hi] - Suy[lo]
236    rul = np.full(t.size, float(max_rul))
237    ok = m >= 3
238    with np.errstate(divide="ignore", invalid="ignore"):
239        slope = (suy - su * sy / m) / (suu - su * su / m)
240        now = sy / m + slope * (u - su / m)  # fitted line at the current time
241        rising = ok & (slope > 0)
242        rul[rising] = np.clip((threshold - now[rising]) / slope[rising], 0, max_rul)
243    rul[ok & (slope <= 0) & (now >= threshold)] = 0.0
244    return rul

247def rul_scores(y_true, y_pred):
248    """Error metrics for RUL predictions.
249
250    Parameters
251    ----------
252    y_true, y_pred : array_like
253        True and predicted RUL (hours).
254
255    Returns
256    -------
257    dict
258        ``MAE_h`` and ``RMSE_h`` in hours, and ``late_%``: share of
259        predictions longer than the true RUL (unsafe direction).
260    """
261    err = np.asarray(y_pred, dtype=float) - np.asarray(y_true, dtype=float)
262    return {"MAE_h": np.mean(np.abs(err)),
263            "RMSE_h": np.sqrt(np.mean(err ** 2)),
264            "late_%": 100 * np.mean(err > 0)}

267def candidate_models(depth=4, C=100.0):
268    """The week 5 regression models, with their flexibility settings.
269
270    Parameters
271    ----------
272    depth : int, optional
273        Decision-tree maximum depth.
274    C : float, optional
275        SVR penalty (larger = more flexible).
276
277    Returns
278    -------
279    dict
280        Name -> unfitted scikit-learn estimator.
281    """
282    return {
283        "mean (Dummy)": DummyRegressor(strategy="mean"),
284        "linear": make_pipeline(StandardScaler(), LinearRegression()),
285        f"tree (depth {depth})": DecisionTreeRegressor(max_depth=depth, random_state=0),
286        f"SVR (C {C:g})": make_pipeline(StandardScaler(), SVR(C=C, epsilon=1.0)),
287    }

290def compare_models(models, X_train, y_train, X_test, y_test):
291    """Fit each model and score it on training and test data.
292
293    Parameters
294    ----------
295    models : dict
296        Name -> unfitted estimator (see `candidate_models`).
297    X_train, y_train, X_test, y_test : array_like
298        Features and true RUL (hours).
299
300    Returns
301    -------
302    pandas.DataFrame
303        One row per model: training MAE, test scores from `rul_scores` and
304        fitting time in milliseconds.
305    predictions : dict
306        Name -> predicted RUL on the test data.
307    """
308    rows, predictions = {}, {}
309    for name, model in models.items():
310        start = time.perf_counter()
311        model.fit(X_train, y_train)
312        fit_ms = 1000 * (time.perf_counter() - start)
313        predictions[name] = model.predict(X_test)
314        train_mae = np.mean(np.abs(model.predict(X_train) - np.asarray(y_train)))
315        rows[name] = {"train_MAE_h": train_mae,
316                      **rul_scores(y_test, predictions[name]),
317                      "fit_ms": fit_ms}
318    return pd.DataFrame(rows).T, predictions

321def complexity_curve(make_model, values, X_train, y_train, X_test, y_test):
322    """Training and test MAE as one setting is varied (overfitting plot).
323
324    Parameters
325    ----------
326    make_model : callable
327        ``make_model(value)`` returns an unfitted estimator.
328    values : iterable
329        Settings to try, e.g. tree depths.
330    X_train, y_train, X_test, y_test : array_like
331        As in `compare_models`.
332
333    Returns
334    -------
335    pandas.DataFrame
336        Indexed by setting, columns ``train_MAE_h`` and ``test_MAE_h``.
337    """
338    y_train, y_test = np.asarray(y_train), np.asarray(y_test)
339    rows = {}
340    for v in values:
341        model = make_model(v).fit(X_train, y_train)
342        rows[v] = {"train_MAE_h": np.mean(np.abs(model.predict(X_train) - y_train)),
343                   "test_MAE_h": np.mean(np.abs(model.predict(X_test) - y_test))}
344    return pd.DataFrame(rows).T

352def tune_and_test(make_model, grid, features, y, roles, clip=True):
353    """Choose settings on validation data, then score once on test data.
354
355    Each candidate is fitted on the ``"train"`` snapshots and its validation
356    MAE recorded. Only the best candidate is applied to ``"test"``, so the
357    test score played no part in the choice (week 5.5).
358
359    Parameters
360    ----------
361    make_model : callable
362        ``make_model(**settings)`` returns an unfitted estimator.
363    grid : list of dict
364        Candidate settings. Each has a ``"smooth"`` key (key of `features`)
365        plus any keyword arguments for `make_model`.
366    features : dict
367        Smoothing window -> feature matrix for all snapshots.
368    y : array_like
369        True RUL (hours) for all snapshots.
370    roles : array_like of str
371        ``"train"``, ``"val"``, ``"test"`` or ``"gap"`` per snapshot
372        (see `splits`).
373    clip : bool, optional
374        Physical constraint: keep predictions between 0 (RUL cannot be
375        negative) and the longest RUL seen in training. Applied when
376        choosing settings as well as when scoring.
377
378    Returns
379    -------
380    dict
381        Chosen settings, ``train_MAE_h``, ``val_MAE_h`` and the test scores
382        from `rul_scores`.
383    numpy.ndarray
384        Predicted RUL for the test snapshots.
385    """
386    y = np.asarray(y, dtype=float)
387    tr, va, te = _masks(roles)
388    hi = y[tr].max() if clip else np.inf
389    lo = 0.0 if clip else -np.inf
390
391    def predict(model, X):
392        return np.clip(model.predict(X), lo, hi)
393
394    best = None
395    for settings in grid:
396        kwargs = {k: v for k, v in settings.items() if k != "smooth"}
397        X = features[settings["smooth"]]
398        model = make_model(**kwargs).fit(X[tr], y[tr])
399        val_mae = np.mean(np.abs(predict(model, X[va]) - y[va]))
400        if best is None or val_mae < best[0]:
401            best = (val_mae, settings, model, X)
402    val_mae, settings, model, X = best
403    pred = predict(model, X[te])
404    train_mae = np.mean(np.abs(predict(model, X[tr]) - y[tr]))
405    return {**settings, "train_MAE_h": train_mae, "val_MAE_h": val_mae,
406            **rul_scores(y[te], pred)}, pred

409def tune_fixed(predictions, y, roles, cap=True):
410    """`tune_and_test` for methods that need no fitting (catalogue, trend
411    extrapolation): pick the precomputed prediction with the lowest
412    validation MAE and score it on test.
413
414    Parameters
415    ----------
416    predictions : dict
417        Settings (tuple or label) -> predicted RUL for all snapshots.
418    y : array_like
419        True RUL (hours).
420    roles : array_like of str
421        Role per snapshot.
422    cap : bool, optional
423        Limit predictions to the longest RUL seen in training, so a flat
424        trend (no predicted crossing) falls back to "as new".
425
426    Returns
427    -------
428    dict
429        ``settings``, ``val_MAE_h`` and the test scores.
430    numpy.ndarray
431        Predicted RUL for the test snapshots.
432    """
433    y = np.asarray(y, dtype=float)
434    tr, va, te = _masks(roles)
435    limit = y[tr].max() if cap else np.inf
436    val_mae = {k: np.mean(np.abs(np.minimum(p[va], limit) - y[va]))
437               for k, p in predictions.items()}
438    key = min(val_mae, key=val_mae.get)
439    pred = np.minimum(predictions[key][te], limit)
440    return {"settings": key, "val_MAE_h": val_mae[key], **rul_scores(y[te], pred)}, pred

443def validation_curve(make_model, grid, features, y, roles, clip=True):
444    """Training and validation MAE for every candidate setting.
445
446    The same fitting as `tune_and_test`, but every setting is reported, so
447    the sensitivity of the error to each setting can be plotted. The test
448    snapshots are not used.
449
450    Parameters
451    ----------
452    make_model, grid, features, y, roles, clip
453        As in `tune_and_test`.
454
455    Returns
456    -------
457    pandas.DataFrame
458        One row per setting: the setting values, ``train_MAE_h``,
459        ``val_MAE_h`` and ``fit_ms`` (fitting time in milliseconds).
460    """
461    y = np.asarray(y, dtype=float)
462    tr, va, _ = _masks(roles)
463    hi = y[tr].max() if clip else np.inf
464    lo = 0.0 if clip else -np.inf
465    rows = []
466    for settings in grid:
467        kwargs = {k: v for k, v in settings.items() if k != "smooth"}
468        X = features[settings["smooth"]]
469        start = time.perf_counter()
470        model = make_model(**kwargs).fit(X[tr], y[tr])
471        fit_ms = 1000 * (time.perf_counter() - start)
472        rows.append({**settings,
473                     "train_MAE_h": np.mean(np.abs(np.clip(model.predict(X[tr]), lo, hi) - y[tr])),
474                     "val_MAE_h": np.mean(np.abs(np.clip(model.predict(X[va]), lo, hi) - y[va])),
475                     "fit_ms": fit_ms})
476    return pd.DataFrame(rows)

505def leave_one_out_by_group(make_model, grid, features, y, test_group, clip=True):
506    """Train on every group but one, choose settings by inner swaps, test on the one left out.
507
508    A group is one bearing's run to failure. Settings are chosen without the
509    test bearing: each training bearing in turn is held out for validation
510    while the model is fitted on the others, and the setting with the lowest
511    mean validation MAE wins. That setting is refitted on all training
512    bearings and scored once on the test bearing.
513
514    Parameters
515    ----------
516    make_model : callable
517        ``make_model(**settings)`` returns an unfitted estimator.
518    grid : list of dict
519        Candidate settings, each with a ``"smooth"`` key (see `tune_and_test`).
520    features : dict
521        Group -> {smoothing window -> feature matrix of that group}.
522    y : dict
523        Group -> true RUL (hours) of that group.
524    test_group : hashable
525        The group scored at the end.
526    clip : bool, optional
527        Keep predictions between 0 and the longest RUL in the fitting data.
528
529    Returns
530    -------
531    dict
532        Chosen settings, ``val_MAE_h`` and the test scores from `rul_scores`.
533    numpy.ndarray
534        Predicted RUL for the test group.
535    """
536    train = [g for g in features if g != test_group]
537
538    def fit_predict(settings, fit_groups, predict_group):
539        kwargs = {k: v for k, v in settings.items() if k != "smooth"}
540        sw = settings["smooth"]
541        X = np.vstack([features[g][sw] for g in fit_groups])
542        target = np.concatenate([np.asarray(y[g], dtype=float) for g in fit_groups])
543        pred = make_model(**kwargs).fit(X, target).predict(features[predict_group][sw])
544        return np.clip(pred, 0, target.max()) if clip else pred
545
546    best = None
547    for settings in grid:
548        val_mae = np.mean([np.mean(np.abs(fit_predict(settings, [g for g in train if g != v], v)
549                                          - np.asarray(y[v], dtype=float)))
550                           for v in train])
551        if best is None or val_mae < best[0]:
552            best = (val_mae, settings)
553    val_mae, settings = best

def extrapolate_rul(t, y, threshold, window=10.0, log=False, max_rul=inf): 
164def extrapolate_rul(t, y, threshold, window=10.0, log=False, max_rul=np.inf):
165    """Predict RUL by extrapolating the recent trend to a failure threshold.
166
167    At each snapshot a least-squares line is fitted to the values in the
168    last `window` hours (only past data). Times are measured from the
169    current snapshot, which keeps the fit well conditioned (week 2.2).
170
171    Parameters
172    ----------
173    t : array_like
174        Hours, increasing.
175    y : array_like
176        Health indicator, usually RMS (g).
177    threshold : float
178        Indicator value treated as failure.
179    window : float, optional
180        Hours of history fitted. Short follows noise, long reacts slowly.
181    log : bool, optional
182        Fit ``log(y)`` instead, i.e. exponential growth.
183    max_rul : float, optional
184        Prediction used when the trend is flat or falling (no crossing).
185
186    Returns
187    -------
188    numpy.ndarray
189        Predicted RUL in hours, between 0 and `max_rul`.
190    """
191    t, y = np.asarray(t, dtype=float), np.asarray(y, dtype=float)
192    if log:
193        y, threshold = np.log(y), np.log(threshold)
194    rul = np.full(t.size, float(max_rul))
195    for i in range(t.size):
196        past = (t <= t[i]) & (t > t[i] - window)
197        if past.sum() < 3:
198            continue
199        slope, now = np.polyfit(t[past] - t[i], y[past], 1)
200        if slope > 0:
201            rul[i] = np.clip((threshold - now) / slope, 0, max_rul)
202        elif now >= threshold:
203            rul[i] = 0.0
204    return rul

def extrapolate_rul_fast(t, y, threshold, window=10.0, log=False, max_rul=inf): 
207def extrapolate_rul_fast(t, y, threshold, window=10.0, log=False, max_rul=np.inf):
208    """Same result as `extrapolate_rul`, in O(n) instead of O(n^2) time.
209
210    `extrapolate_rul` runs a Python loop that builds a boolean mask over
211    all n snapshots and calls `numpy.polyfit` at every snapshot, so its cost
212    grows as n^2 (in practice the ~50 us overhead of each `polyfit` call
213    dominates at IMS sizes). Here the least-squares sums come from running
214    (cumulative) sums, vectorised over all snapshots, so each window costs
215    a few subtractions:
216    $b = S_{ty} / S_{tt}$ with $S_{tt} = \\sum t^2 - (\\sum t)^2/m$ and
217    $S_{ty} = \\sum ty - \\sum t \\sum y / m$ over the m points in the window.
218
219    Subtracting large running sums loses digits (catastrophic cancellation,
220    week 2.2), so times are first centred on their mean, which keeps the
221    sums small. `test_rul_models` checks the two versions agree to 1e-6 h.
222
223    Parameters and return value are as in `extrapolate_rul`; `t` must be
224    strictly increasing.
225    """
226    t, y = np.asarray(t, dtype=float), np.asarray(y, dtype=float)
227    if log:
228        y, threshold = np.log(y), np.log(threshold)
229    u = t - t.mean()                        # centred times, smaller sums
230    zero = [0.0]
231    S1, Su, Sy, Suu, Suy = (np.concatenate([zero, np.cumsum(v)])
232                            for v in (np.ones_like(u), u, y, u * u, u * y))
233    hi = np.arange(1, t.size + 1)           # window is snapshots lo .. hi-1
234    lo = np.searchsorted(t, t - window, side="right")
235    m, su, sy = S1[hi] - S1[lo], Su[hi] - Su[lo], Sy[hi] - Sy[lo]
236    suu, suy = Suu[hi] - Suu[lo], Suy[hi] - Suy[lo]
237    rul = np.full(t.size, float(max_rul))
238    ok = m >= 3
239    with np.errstate(divide="ignore", invalid="ignore"):
240        slope = (suy - su * sy / m) / (suu - su * su / m)
241        now = sy / m + slope * (u - su / m)  # fitted line at the current time
242        rising = ok & (slope > 0)
243        rul[rising] = np.clip((threshold - now[rising]) / slope[rising], 0, max_rul)
244    rul[ok & (slope <= 0) & (now >= threshold)] = 0.0
245    return rul

507    """Train on every group but one, choose settings by inner swaps, test on the one left out.
508
509    A group is one bearing's run to failure. Settings are chosen without the
510    test bearing: each training bearing in turn is held out for validation
511    while the model is fitted on the others, and the setting with the lowest
512    mean validation MAE wins. That setting is refitted on all training
513    bearings and scored once on the test bearing.
514
515    Parameters
516    ----------
517    make_model : callable
518        ``make_model(**settings)`` returns an unfitted estimator.
519    grid : list of dict
520        Candidate settings, each with a ``"smooth"`` key (see `tune_and_test`).
521    features : dict
522        Group -> {smoothing window -> feature matrix of that group}.
523    y : dict
524        Group -> true RUL (hours) of that group.
525    test_group : hashable
526        The group scored at the end.
527    clip : bool, optional
528        Keep predictions between 0 and the longest RUL in the fitting data.
529
530    Returns
531    -------
532    dict
533        Chosen settings, ``val_MAE_h`` and the test scores from `rul_scores`.
534    numpy.ndarray
535        Predicted RUL for the test group.
536    """
537    train = [g for g in features if g != test_group]
538
539    def fit_predict(settings, fit_groups, predict_group):
540        kwargs = {k: v for k, v in settings.items() if k != "smooth"}
541        sw = settings["smooth"]
542        X = np.vstack([features[g][sw] for g in fit_groups])
543        target = np.concatenate([np.asarray(y[g], dtype=float) for g in fit_groups])
544        pred = make_model(**kwargs).fit(X, target).predict(features[predict_group][sw])
545        return np.clip(pred, 0, target.max()) if clip else pred
546
547    best = None
548    for settings in grid:
549        val_mae = np.mean([np.mean(np.abs(fit_predict(settings, [g for g in train if g != v], v)
550                                          - np.asarray(y[v], dtype=float)))
551                           for v in train])
552        if best is None or val_mae < best[0]:
553            best = (val_mae, settings)
554    val_mae, settings = best
555    pred = fit_predict(settings, train, test_group)
556    return {**settings, "val_MAE_h": val_mae, **rul_scores(y[test_group], pred)}, pred
