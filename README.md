# Bearing Degradation Monitoring from Vibration Data

**MMA3001 Numerical Methods and Machine Learning, Project**
Author: Ryan

This project tracks the health of a rolling-element bearing from vibration measurements, using the NASA IMS run-to-failure dataset. It turns raw accelerometer recordings into condition indicators (RMS, kurtosis, peak), then uses them to detect when a fault starts and to model how the bearing degrades towards failure.

## Engineering problem

Rolling-element bearings are among the most common causes of failure in rotating machinery such as pumps, motors, gearboxes and turbines. An unexpected bearing failure can mean costly downtime or secondary damage. *Condition-based maintenance* replaces parts when the measured condition shows they are wearing out, instead of on a fixed schedule. That requires:

1. a reliable **health indicator** computed from vibration data, and
2. a way to **detect the onset of a fault** and estimate how it progresses.

## Data

**NASA IMS Bearing Dataset** (Center for Intelligent Maintenance Systems, University of Cincinnati), from the NASA Prognostics Data Repository.

- Four Rexnord ZA-2115 double-row bearings on one shaft at 2000 RPM, with a 6000 lb radial load.
- Each file is a 1 s snapshot of 20,480 samples at 20 kHz. File names are timestamps.
- **Test 2** (used here): 984 snapshots taken every 10 minutes from 12 to 19 Feb 2004. It ends with an outer-race failure in **bearing 1**.

The raw data (about 6 GB) is **not stored in this repository**. Download it from the NASA Prognostics Data Repository and point the code at the `2nd_test` folder.

> Qiu, H., Lee, J., Lin, J., & Yu, G. (2006). Wavelet filter-based weak signature detection method and its application on rolling element bearing prognostics. *Journal of Sound and Vibration*, 289, 1066–1090.

## Inputs and outputs

| | Description |
|---|---|
| **Input** | Folder of IMS snapshot files: tab-separated ASCII, one column per accelerometer channel, acceleration in g |
| **Output** | Feature table (`features_2nd_test.csv`): one row per snapshot, indexed by `sample`, with `file`, `rms_k`, `kurtosis_k` and `peak_k` for each channel k |
| **Invalid input** | A missing folder or empty folder raises `FileNotFoundError`. Empty or non-numeric files raise `ValueError`. Google Drive duplicate files (`name (1)`) are skipped. A constant signal gives NaN kurtosis. |

Full function-level inputs and outputs are in the [HTML documentation](docs/bearing_features.html).
